# P&G 수주·배송 포털 시연 시나리오 (납품일 2026-11-26 기준)

## 준비 (시연 전날 또는 당일 아침)

1. 포털 서버를 끈다.
2. 시연 데이터를 다시 만든다(이전 DB는 data/backups에 자동 백업).

   ```
   py tools\seed_demo_1126.py 2026-11-26
   ```

3. `실행.bat`으로 서버를 켠다 → http://127.0.0.1:5070 (같은 사무실 PC·폰에서 열려면 이 PC의 IP로, 기사 GPS 시연은 HTTPS 필요).
4. 폰으로 기사 화면을 보여줄 거면 배차 화면에서 기사 링크를 복사해 카톡으로 보내 두거나, 차량별 배정표의 QR을 띄워 둔다.

| 계정 | 아이디 / 비밀번호 | 역할 |
|---|---|---|
| 관리자(TPL2) | 1111 / 1111 | 전체 |
| 천안센터 | center1 / demo1234 | 자기 센터 오더·배차 |
| SAMMI | sammi / demo1234 | 배차·반품 배차 |
| P&G 담당자 | pg_user / demo1234 | 오더 조회·반품 등록 |
| 기사 | 계정 없음 | 배차 화면의 링크 또는 차량번호 + 휴대폰 뒷 4자리 |

시연 데이터: 출고센터 2(천안·안성), RDC 5(대전·광주·부산·대구·원주), 납품처 20, 상품 12, 차량 8(11톤 4·5톤 2·3.5톤·2.5톤), 11/26 오더 22건(정상 20·오류 2), 반품 7건.

## 시연 순서 (약 15분)

### 1. 현황판 (관리자 로그인 → 현황, 조회일 2026-11-26)
- 상태 카드: RDC 분리 7, 배차, 센터도착·센터출발·점포도착, 배송완료, 오류 2 등 한눈에.
- "직송 배송 진행" 표: 81나2001은 광명점 완료(인수증·123m 반경 내), 수원점 점포 도착, 81나2002는 센터 출발 후 해운대로 이동 중(예상도착 표시), 81나2003은 센터 도착.
- 차량별 적재율(VFR): 직송 차량(11톤 4대)만 집계.
- 말할 것: 오더·배차 데이터가 들어오면 이 화면이 운영의 기준이 된다.

### 2. 오더 업로드 → 검증 → 판정 (오더 업로드 메뉴)
- `예시파일\시연_PG오더_20261127_추가.xlsx`(11/27 오더 3건)를 끌어다 놓고 "검증하기".
- 보여줄 것: 컬럼 자동 인식(PO번호, Ship-to, Material, AREA CODE, 출고센터), 요약 카드, "일자+납품처별 PLT 합계와 직송/RDC 예상 판정" 표(수원 6 PLT → 직송, 천안 2 PLT → 대전 RDC, 해운대 2 PLT → 부산 RDC).
- 직송 기준 PLT 칸에 2를 넣고 "등록 확정" → 해운대가 직송으로 바뀌는 것을 오더 목록에서 확인(기준은 날짜마다 담당자가 정한다는 점 강조).
- 오류 처리: 오더 목록에서 상태 '오류' 2건(납품처 미등록 S9999, 상품 미등록 89999) → 마스터 보완 후 재업로드하거나 보류하는 흐름 설명.

### 3. 분리·양식 (분리·양식 메뉴, 11/26)
- 상단 "직송 기준 PLT 3" 입력칸과 납품처별 표: 합계 PLT, 현재 유형, 근거. 울산점을 "직송"으로 직접 지정 → 배지가 바뀌고 "담당자 지정" 표시. "규칙"으로 되돌리기.
- 4개 카드(안성 직송 10 / 안성 RDC 0 / 천안 직송 3 / 천안 RDC 7)에서 "수주 양식" 내려받기 → GAON 업로드 양식 엑셀 열어 보이기.
- "천안센터 피킹리스트 인쇄 화면" → 상품 총량과 납품처별 내역(확인란).
- "글로비스 작업지시 배차·착지 엑셀" 내려받기.

### 4. 가온 등록 (가온 등록 메뉴)
- 대기 2건(강릉·원주)이 남아 있음. 실제 연결은 HAR 분석 후이며 지금은 양식 업로드로 대체한다고 설명. 나머지 20건은 전표번호가 기록된 상태.

### 5. 배차·적재율 (배차 메뉴, 11/26)
- 미배차 1건(용인흥덕점 직송)이 보임 → "자동배차 실행" → 남은 용량 있는 차량에 배정되고 적재율 표가 갱신됨(또는 차량번호를 직접 입력해 수동 배차).
- 표에서 기사 링크 "복사" → 카톡에 붙여넣는 시늉 / "차량별 배정표·QR" 새 창 → QR 인쇄물 설명.
- 배차 해제·재배정, 용차 차량번호 직접 입력(없는 차량은 자동 등록) 시연.
- RDC 오더는 배차 대상이 아니며 분리·양식 단계에서 끝난다(상태 'RDC 분리').

### 6. 기사 화면 (폰 또는 브라우저 모바일 보기)
- 배차 화면에서 81나2003(오세훈) 링크를 복사해 열기 → 성수점이 "센터도착" 상태. "센터 출발" 버튼 → 위치 확인 → 예상 도착 시각 표시(점포 SMS 큐 생성). "점포 도착" → 반경 검증 문구. "배송 완료" → 인수자·사진.
- 링크 없이: /m/login 에서 차량번호 81나2003 + 뒷자리 1007.
- 관리자 화면으로 돌아와 현황판에서 방금 단계가 반영된 것을 보여줌.
- 참고: 폰 GPS는 HTTPS에서만 동작. 사내 PC 브라우저 시연에서는 "위치 없이 처리"로 진행.

### 7. P&G 화주 화면 (pg_user 로그인)
- 오더 조회·추적: 11/26 오더 현재 상태·예상도착·완료시각. 오더 클릭 → 단계별 시각, 인수증, 이력.
- 월 실적 탭.
- 반품 메뉴 → "+ 반품 등록"(납품처 S2003 홈플러스 청주, 5 BOX, 유통기한) → 등록.

### 8. 반품 (관리자 → 반품)
- 목록: 등록 1·거점 안내 1·배차 1·입고확인 1·정산 3. 방금 P&G가 등록한 건을 체크 → "선택 건 거점 안내 메일" → 대전 RDC 묶음 메일 본문 생성(SMTP 없어 복사용).
- sammi 로그인 → 반품 배차(차량 82다3001) → 회수 완료 → 관리자 입고확인.
- "월별 BOX 대시보드": 거점·납품처·사유별 BOX, 추이, 11월 정산 마감 버튼, 엑셀.

### 9. 관리 (관리자)
- 알림 큐: 기사 출발·도착 SMS 5건 대기(비용 확인 후 대행사 키 연결).
- 설정: 판정 기본값, 가온 화주코드, 지오코딩 키, 자동배차 상한, SMS·메일, GAON 양식 컬럼.
- 마스터: 납품처(AREA CODE·거점·강제 유형·좌표), 상품(입수·CBM), 차량(적재 PLT·CBM·운송사), 출고센터, 거점(RDC·반품 메일).

## 자주 받는 질문 대비

- 직송/RDC 기준: 날짜별 기준 PLT(담당자 입력) → 납품처 강제 유형 → 담당자 직접 지정 순. 설정의 3은 기본값.
- 자동배차: 직송만 대상. 권역·좌표 순으로 묶어 큰 차량부터 PLT·CBM 상한(95%)까지 채움. 톤수 선택 규칙은 운영 기준 확인 후 반영 예정. RDC 오더는 분리·양식까지만.
- 가온 연동: 로그인·조회 통신은 검증 완료, 수주 업로드 통신은 HAR 확보 후 연결. 그 전까지 양식 다운로드.
- SMS·메일: 알림톡 6~9원/건, 문자 8~20원/건. 비용 확인 전까지 큐에 보관.
- 기사 앱: 설치·가입 없음. 링크(기기 묶음·납품일+1일 만료) 또는 차량번호+뒷자리.
